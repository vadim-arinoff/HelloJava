# Задание Moodle 2: студенты, книги и Stream API  
  
## Цель  
  
Создать отдельное учебное приложение, которое читает студентов и их книги из JSON-файла, формирует `List<Student>` и выполняет всю требуемую обработку одной цепочкой Stream API без промежуточных переменных в `Main`.  
  
## Как работает Stream API  
  
В методе `Main.process()` используется одна цепочка:  
  
- `peek` выводит каждого студента и не прерывает поток;  
- `map` получает у каждого студента `List<Book>`;  
- `flatMap` объединяет несколько списков в один поток книг;  
- `sorted` сортирует книги по количеству страниц;  
- `distinct` удаляет одинаковые книги с помощью `Book.equals()` и `Book.hashCode()`;  
- `filter` оставляет книги, выпущенные после 2000 года;  
- `limit(3)` оставляет не больше трёх книг;  
- второй `map` превращает книги в годы выпуска;  
- `findFirst` — короткозамыкающая терминальная операция: она прекращает поиск после первого элемента и возвращает `Optional<Integer>`;  
- `ifPresentOrElse` выводит найденный год или сообщение об отсутствии подходящей книги.
