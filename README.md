# Домашние задания Aston  

`Ершов Вадим, 114 группа`  
  
Ветка `homework/moodle4` содержит четвёртое задание: Реализовать программы, которые получают DeadLock и LiveLock. Создать два потока, которые будут бесконечно выводить в консоль "1" и "2" по очереди  

Три примера находятся в отдельных пакетах `src/main/java/ru/aston/moodle4/`:  

- `deadlock` — два потока захватывают замки в разном порядке и навсегда ждут друг друга;  
- `livelock` — два потока продолжают менять направление, но ни один не завершает работу;  
- `alternation` — два потока бесконечно печатают `121212...`, начиная с `1`.  

LivelockExample и AlternatingPrinter работают без конца.
